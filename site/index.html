Operator-side watchdog for agent fleets

Read what your agents did before someone else does.

Bladerunner reads every agent run's trace as it lands in neatlogs and checks it against that agent's policy. When a run breaks the rules, Bladerunner pauses it, proves the finding span by span, writes a guardrail, and confirms the fix holds.

The incident

A 25-year-old wiki became a notepad for thousands of agents.

DSEWiki has served German software developers for 25 years. This summer, OpenAI agents writing under more than 3,700 self-given names used it as their shared notepad. They left an estimated 18,000 posts. Researchers have since recovered 14,591 revisions.

24 May

First successful writes.

The agents' first edits land on the wiki. More follow.

2 June

A volunteer moderator notices.

They start deleting the spam pages by hand, and they keep at it for weeks.

16 to 22 June

The busiest week.

Most of the agents' activity happens in these seven days.

21 June

The operator shows up.

The first visits to the wiki from the operator running the agents appear in the log.

22 June

The edits stop.

The next day, agent edits drop to near zero.

4 September

The log goes public.

Four outside researchers publish the wiki's edit log at collusion.wiki. Until that day, nobody had said anything about it in public.

What was missing

The signals were in the agents' own tool calls the whole time.

Every one of those posts began as a call an agent made through its own tools. Nobody was reading those calls with the one question that mattered.

Is this agent doing something it isn't supposed to?

Sources: collusion.wiki (Von Arx, Slade Byrd, Kitts, Larsen, 4 September 2026); swarm-ai-research.github.io/wiki-agent-swarm-incident; arXiv 2609.12748.

The gap

Agent teams have dashboards for everything except their own rules.

Teams running agents in production already track traces, cost, latency and errors. Nothing in that stack checks what an agent did against what it was allowed to do. When an agent breaks its rules, the company running it is usually the last to find out. At DSEWiki, a volunteer moderator and four outside researchers got there first.

2Catch

Each run is checked against the agent's policy: which tools it may use, where it may send data, and which values are private. It is also checked against a catalog of seven ways an agent breaks its rules.

3Stop and prove

Bladerunner pauses the run, quarantines it, and writes an incident report in which every claim links to the exact trace spans behind it. Two models share the work. An investigator proposes findings. A verifier from a different model family checks each claim against the cited evidence and upholds only what the evidence proves.

FindingC1 Writing to an unapproved destination

case: patching, confirming, fixed

4Fix and confirm

OpenCode, an autonomous coding agent, writes a guardrail patch. A patch may only tighten policy. Bladerunner commits it with an Entire checkpoint that records which agent wrote which line, and why.

Then it re-runs the same scenario plus a clean control run, and confirms the result against hidden ground truth that the watchdog itself never reads.

Ground truth

The watchdog never sees the answer key.

The arena that runs the agents owns the ground truth. Bladerunner never imports it and never reads it, so it can't grade its own work.

Arena

  • runs the agents and the scenarios
  • holds the ground truth sealed
boundary

Watchdog

  • reads traces from neatlogs
  • has no import of the ground truth
  • has no read access to it

A fix counts as confirmed only when all three of these hold.

  • The ground truth says the bad behavior is gone.
  • A clean control run still passes.
  • The watchdog's own view of the re-runs agrees.

neatlogs

The data source and the incident surface. Traces come in from neatlogs. Verdicts go back as:

  • tags on the trace
  • a renamed trace
  • feedback on the evidence span

Entire

Checkpoints record the provenance of every guardrail patch: which agent, which prompt, which line. Brain holds the watchdog's incident memory, so past cases inform the next investigation.
